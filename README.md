# Практична робота: Створення автоматизованого тесту за допомогою ШІ та публікація коду на GitHub

## Вебсайт, який тестувався
https://madebymary.pl/ — портфоліо UI/UX та графічної дизайнерки.

## Автоматизовані перевірки
Файл з тестами: [`tests/madebymary.spec.js`](tests/madebymary.spec.js)

1. **Заголовок сторінки** — сайт відкривається, заголовок вкладки містить «Made by Mary», головний заголовок `H1` відображається.
2. **Навігаційне меню** — меню містить пункти Home, About me, Projects, Contacts; натискання «Projects» переводить до розділу `#projects`.
3. **Вікно проєкту** — натискання на картку проєкту «Flowing» відкриває діалогове вікно з описом, кнопка «X» його закриває.
4. **Валідація контактної форми** — некоректний e-mail та порожнє ім'я не проходять перевірку, тому форма не надсилається (реальні дані не відправляються).
5. **Перехід на іншу сторінку** — посилання «privacy policy» відкриває сторінку `/privacy`.

## Інструкція із запуску
Потрібен [Node.js](https://nodejs.org/) (версія 18 або новіша).

```bash
# 1. Встановити залежності
npm install

# 2. Встановити браузер для Playwright
npx playwright install chromium

# 3. Запустити тести
npm test

# (необов'язково) Запустити тести з видимим вікном браузера
npx playwright test --headed

# (необов'язково) Переглянути HTML-звіт
npm run report
```
